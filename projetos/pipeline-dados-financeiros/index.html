Portfólio

Pipeline de Dados Financeiros

Python · ETL • Código no GitHub ↗

Visão geral

Pipeline ETL em Python que processa 100.000 transações bancárias simuladas: valida e padroniza CPFs, datas e valores monetários, rejeita registros inválidos com motivo registrado em log e converte o resultado de CSV para Parquet.

Resultados

  • 63% de compressão — arquivo Parquet 63% menor que o CSV original
  • 9,4× mais rápido — queries sobre o Parquet são 9,4x mais rápidas
  • 6.937 registros inválidos rejeitados com motivo registrado no log
  • 8 testes automatizados com Pytest cobrindo validação e conversão

Stack utilizada

  • Python · Pandas · PyArrow
  • Pytest (testes automatizados)
  • Parquet (formato colunar)
