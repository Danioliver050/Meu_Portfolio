Portfólio

Data Lake com Arquitetura Medalhão

Python · DuckDB • Código no GitHub ↗

Visão geral

Pipeline de Engenharia de Dados em Python que implementa a arquitetura Medalhão (Bronze → Prata → Gold). Processa 50.000 propostas de crédito simuladas, aplicando limpeza, validação e enriquecimento em cada camada e entregando um star schema consultável via DuckDB, com documentação de decisões técnicas e estimativas de custo para migração futura para cloud.

Resultados

  • Star schema com tabela fato_propostas + 4 dimensões consultável via SQL
  • 9 testes automatizados com Pytest cobrindo cada camada do pipeline
  • Dados sintéticos gerados com Faker para simulação realista
  • Documentação de decisões técnicas e estimativas de custo para cloud

Stack utilizada

  • Python · Pandas · DuckDB
  • Pytest · Faker
  • Arquitetura Medalhão (Bronze / Prata / Gold)
